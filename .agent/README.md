# .agent 디렉토리 가이드

이 디렉토리는 Antigravity 에이전트(AI 코딩 어시스턴트)가 이 저장소에서 일관되고 효율적인 작업을 수행하기 위한 **규칙(Rules)**과 **기술(Skills)**을 보관하는 곳입니다.

## 디렉토리 구조

```text
.agent/
├── rules/
│   └── AGENT_RULES.md       # 에이전트 행동 지침 및 코딩 컨벤션
├── skills/
│   ├── deployment/          # Vercel 배포 및 환경 변수 관리 기술
│   ├── data-fetching/       # Supabase 연동 및 데이터 아키텍처 기술
│   └── ui-standards/        # Tailwind v4 및 UI/UX 표준 가이드
└── README.md                # (본 문서)
```

## 사용법

1.  **에이전트**: 작업을 시작하기 전 반드시 `rules/AGENT_RULES.md`를 숙지하고, 각 작업 유형에 맞는 `skills/` 하위 기술 문서를 참고합니다.
2.  **사용자**: 에이전트의 작업 방식이 마음에 들지 않거나 새로운 기술적 제약 사항이 생기면 이 디렉토리 아래의 문서를 직접 수정하거나 에이전트에게 업데이트를 요청할 수 있습니다.

## 규칙 및 기술 업데이트 원칙
- 새로운 기술적 패턴이나 반복되는 작업 프로세스가 발생하면 새 `SKILL.md`를 생성하여 에이전트의 역량을 확장합니다.
- 기술 스택 변경 시(예: Tailwind v4에서 다른 라이브러리로 전환 등) `rules/` 및 `skills/` 문서를 최우선으로 업데이트하여 컨텍스트 일관성을 유지합니다.
