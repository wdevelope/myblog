# 작업 목록

남은 일만 한 줄씩 적는다. 위에 있을수록 먼저 하고, 자세한 계획과 결과는 [로드맵](roadmap.md)의 번호 절에 있다.

- 상태: `[ ]` 할 일, `[~]` 진행 중. 끝난 줄은 지우고 결과는 로드맵 해당 절과 진행 현황에 남긴다.
- 지금 할 수 없는 일은 줄 끝에 `(대기: 이유)`를 붙인다.
- 큰 기능·구조 변경은 로드맵에 새 번호 절로 계획을 쓰고 확인받은 뒤, 여기에 한 줄을 더한다.

## 사용자 (코드 밖)

- [ ] 운영 DB·Storage 백업 — `pg_dump`와 Storage 세 버킷을 저장소 밖 암호화된 곳에 받아 둔다(로드맵 1절)
- [ ] Supabase 옛 키 교체 — `anon`·`service_role` 키가 2026년 말 폐기 예고 상태다. 개발 프로젝트부터 같은 변수 이름에 새 키를 넣는다
- [ ] GitHub 취약점 알림 켜기 — 저장소 설정의 Dependabot alerts와 security updates
- [ ] 유출 비밀번호 차단 켜기 — Supabase Auth의 Leaked password protection이 꺼져 있다(대기: Pro 플랜 기능, 로드맵 알려진 문제 보안 15)
- [ ] 시크릿 창에서 실제 가입 확인 — 운영은 이메일 확인이 켜져 있는데 실제 가입은 테스트로 대체했다. 프로젝트 팀원이 아닌 메일로 가입해 메일이 오는지 본다(로드맵 18절)

## 확인 (배포·운영)

- [ ] 관리자 글 저장의 운영 로그와 체감 속도 확인(로드맵 23절)
- [ ] 방명록 로그인 흐름 확인(로드맵 20절)
- [ ] 실제 발행·삭제 확인(로드맵 7절)

## 코드

- [ ] route group 풀기 — `(home)`·`(list)` 네 곳에 `loading.tsx`가 없어져 둘 이유가 사라졌다. 주소는 그대로다
- [ ] `--webpack` 제거 검토 — 플래그 없이 빌드해 경로 표를 비교한다. 개발은 이미 Turbopack이다
- [ ] Node 버전 고정 — `engines`·`.nvmrc`가 없다. Vercel의 지금 값을 먼저 보고 `package.json`·CI·`@types/node`를 맞춘다
- [ ] `router.refresh()` 중복 — 액션이 이미 새 화면을 돌려주는데 11곳이 같은 화면을 한 번 더 받는다
- [ ] 비공개 규칙을 실제 DB로 확인하는 일정 검사 — 테스트는 Supabase를 모두 가짜로 바꿔 RLS를 보지 못한다. GitHub Actions 일정으로 돌린다
- [ ] 점검의 작은 항목 — 보고 있는 카테고리를 바꾸면 404, 다이어리 쪽 번호가 범위를 넘으면 빈 목록, 아이디 저장 스위치, 모바일 메뉴가 지금 화면 링크에서 안 닫힘, 어두운 모드 토스트, 달력의 글 있는 날 대비(4.13)
- [ ] 테스트의 작은 구멍 — 조건이 빠져도 조용히 틀리는 쿼리(`deleteComment`, `savePost`의 이전 글 조회·`onConflict`, `loadDiaryIndex`)의 인자 확인, 방문자 다이어리 상세·없는 카테고리와 쪽의 404·`DeletePostButton` 테스트
- [ ] 카테고리 없는 공개 글이 방문자에게 안 보임 — anon RLS `posts_select_public`이 공개 카테고리 행을 요구해 목록·상세·검색·sitemap·RSS에서 빠지고 "전체 글" 수에서도 빠진다(로드맵 알려진 문제 동작·데이터)
- [ ] 관리자 피드 목록이 본문까지 전부 읽는다(페이지네이션 없음, 로드맵 알려진 문제 성능·SEO)
- [ ] sitemap이 공개 아티클 1000개에서 잘리고 본문까지 읽는다(로드맵 알려진 문제 성능·SEO)
- [ ] 다이어리 상세의 조회수 표시가 세지 않는 값이다(로드맵 알려진 문제 동작·데이터)
- [ ] 댓글·방명록 알림 메일 운영 확인(대기: 나중에 하기로 함, 로드맵 20절)
- [ ] 다이어리 목록 나눠 읽기 — PostgREST 응답 상한 1000행에서 조용히 잘린다(대기: 다이어리 800개쯤, 로드맵 알려진 문제 동작·데이터)
- [ ] 비공개 카테고리 글 이미지 버킷 — 저장 때 카테고리 공개 범위까지 보게 고친다(대기: 그런 글에 이미지를 쓰기 시작하면, 로드맵 알려진 문제 보안 16)
